Додати ліки для: Мама
Розклад

Поля — лише ОБРАНОГО типу (тут «Певні дні тижня» → перемикачі-чипи днів + час). Щодня → «скільки разів/день» (select) + час(и); Курс → «дата від» / «дата до» (date-пікери); За потреби → без полів. Час/дати/дні — СИСТЕМНІ контроли, не вільний текст. *(Дефолт у продукті — Щодня; тут показано «Певні дні», щоб видно було вибір днів.)*

Нагадування
–

«За скільки» — dropdown; «час» / «тихі години» — системні time-пікери (не вільний текст). push недоступний (iOS) → fallback: локальне/email + видимий статус. Не тупик.
