# Microcopy — інвентар голосу (КРОК 10 · режим ІНВЕНТАР)

Перепис **усього тексту інтерфейсу** з `wireframes/*.html` (48 файлів) в одну таблицю
для крос-екранного порівняння. Поки це **дзеркало наявного** — нічого не переписано.
За §9 стане **джерелом правди копірайту**: таблицею, з якою звіряється кожен продуктовий
рядок; далі відобразиться в наявному `index.html` (окремого `voices.html` НЕ створюємо).

> ⚠️ **Демо-дані перейменовано.** Активний демо-профіль тепер **«Олена» (імʼя) + «мама»
> (роль)** — канон у [`_fixtures.md`](./_fixtures.md) (раніше імʼя дублювало роль: «Мама /
> мама»). Рядки нижче, де стоїть «Мама», стосуються **того самого профілю** — читати як
> «Олена». У блоках **change-log «було → стало»** «Мама» лишається **як історична цитата**
> (історію не переписуємо). Це **дані** (голос **Д**), не продуктовий копірайт.

## Легенда

**Чий голос:**
- **П** — *продукт*: наш постійний microcopy (заголовки, кнопки, підписи полів, стани, хінти). **Над цим працюємо.**
- **Д** — *дані*: приклад доменного контенту / ввід користувача (імена-ролі, назви ліків, значення, дати, нотатки лікаря). **НЕ наш голос — не чіпаємо** (наведено лише репрезентативно, для звірки консистентності).
- **П§0** — *слот-бокс* (§0): плейсхолдер ассета (крива, знімок, аватар, іконка). Навмисний, не копі.
- *риштування* (`wf-note`, `wfnav`, compare-бар, disabled-стаби, HTML-коментарі) — **виключено** з інвентарю голосу (не копі; там же «заборонені слова» аудиту — це мета-нотатки, не UI).

**Тип рядка:** Заголовок · Секція · Кнопка · Поле · Опція · Порожній · Помилка · Завантаж. · Статус · Хінт · Nav.

**Позначки розсинхрону** нижче за таблицею (§1–§5 + дані). ⚑ = потребує рішення; ★ = критично.

#### Застосування voice.md → dashboard (планка) · було → стало

Перший екран, застосований за `voice.md` (§9: спершу тут — копі-правда, тоді HTML). Стани зі
`_screens.md`: dashboard = **база + порожній** (`-error`/`-loading` не існують — не малюємо). Змінено
**лише видимий продуктовий текст**; дані / риштування / структура — недоторкані.

| Файл | Рядок (зона) | Було | Стало | Причина |
|---|---|---|---|---|
| `dashboard` | sr-only h1 | Головна — **картка**: Мама | Головна — **профіль**: Мама | Словник: «картка» зарезервовано за «Базова картка»; людина = «профіль». |
| `dashboard-empty` | sr-only h1 | Головна — **картка**: Мама (порожньо, холодний старт) | Головна — **профіль**: Мама (порожньо, холодний старт) | те саме (Словник). |
| `dashboard-empty` | ② Сьогодні · CTA | Додати **перший запис** | Додати **ліки чи візит** | ⚑G: генерик «запис» + неконсистентність; конкретно за кластером «Сьогодні» (ліки/візити), Словник-терміни (P4 / Мікрокопі-кнопка). |
| `dashboard-empty` | ③ Останнє · порожній | **Ще немає записів.** | **Тут з'являться документи й аналізи.** | P4 — вперед-дивиться (як Сьогодні), паралельно; прибрано генерик «записів»; конкретно (Останнє = документи/аналізи). |
| `dashboard-empty` | ③ Останнє · CTA | Додати документ, **ліки** чи аналіз | Додати документ **чи аналіз** | ⚑G: конкретно за кластером Останнє (документи/аналізи; «ліки» належать Сьогодні); паралельна структура з рештою CTA. |

**Залишено свідомо (вже voice-коректне — планка показує, що джерело писалось чисто):**
- ⚑B «Критичне» (секція) + «Базова картка» (кнопка) — **вирішено Словником**: «Критичне» = ярлик кластера дашборда (sitemap), «Базова картка» = запис, який кнопка відкриває; різні рівні → обидва лишаються.
- ⚑A «Перемкнути профіль» — dashboard **уже** на правильному боці (профіль, не «член»).
- Лід/хінти («Kartka поки порожня — почніть із критичного…», «Внесіть критичне… навіть офлайн», «ще не внесені») — уже P4 (запрошення, не докір) + P2; лишаються.
- Дані недоторкані: імена/ролі (Мама), значення (Гемоглобін 128 г/л), дати, «· аналіз»-тег.

**МЕЖА (порядково):** жоден зі змінених рядків не оцінює / не нормує / не радить. ДОЗВОЛЕНЕ збережене
(порожні хінти запрошують; жодного «стало краще» / «успішно» / вироку).

### §3. Невідповідний тон

- **Загалом — спокійно й доречно ✓.** Немає «Вітаємо!», зайвих оклич­ників, емодзі поза дозволеним (✓/＋ — гліфи, не бадьорі емодзі). Помилки — durable й без драми («Введене не втрачено»). Empty = запрошення внести критичне, не докір. Deadempty — спокійна профілактика.
- ⚑ **Узгодження роду/гендер (клас).**
  - «Ще не **позначав** прийомів» (`medication-detail-empty:46`) — чоловічий рід дієслова; caregiver може бути будь-якої статі (профіль — «Мама»). → нейтрально («Прийомів ще не позначено»).
  - «Сфотографуйте **виписку** (ж.р.), рецепт чи результат — і **він**…» (`documents-empty:40`) — займенник не узгоджений із провідним іменником змішаного списку (виписку ж. · рецепт ч. · результат ч.). → множина «вони будуть» / нейтр. «все буде» / назвати «документ буде».
- ⚑ **Жаргон.** «з кешу» / «Показати **кешований**» / «синхронізується…» — технічніше за вже прийняті durable-рядки «збережено локально» / «у черзі». Звірити регістр «кеш»-лексики (не для кінцевого користувача).

### §4. МЕЖА (найкритичніше) — 🟩 порушень НЕ виявлено, 2 watch-точки

**Перевірено КОЖЕН рядок усіх 48 екранів.** Жодного: «у нормі», «поза межами»,
«покращується/погіршується», «ви пропустили», «недостатньо для…», стрілок «краще/гірше»,
стріків, %, «дисципліни», target-line, вердиктів. Крива = сирий слот+значення+зум. **Межа тримається.**

Дозволені факт-рядки (не судження) на місці й коректні:
«потрібен ще ≥1 запис» (n=1), «Це не вся історія — внесено мало записів» (неповна), «не внесено» (todo).

**2 watch-точки (нині чисті — тримати такими):**
- 🟨 «**пропущено**» — статус дози в журналі (`medication-detail:51`). Це **сирий event-статус** окремої дози (ОК). Заборонено агрегувати чи оцінювати: «2 пропущені поспіль», «часто пропускаєте», % пропусків — це вже перетне межу.
- 🟨 «Наступний огляд **лікар радив** за 6 місяців» (`visit-detail-past:50`). Порада **атрибутована лікарю** (ОК — Kartka зберігає сказане). Тримати атрибуцію завжди; Kartka ніколи не радить від себе.

### §5. Тексти-заглушки — не виявлено ✓

Продуктових lorem/стабів немає. `.todo` = доменні лейбли порожніх полів («не вказано» / «не внесено» / «не позначено»). `slot-box` = §0-плейсхолдери ассетів (крива, знімок, аватар, іконка — навмисні). Disabled-стаби R4 («далі (R4)») прибрано Фазою 2.

## Підсумок для §8 (полірування копі — далі, не тепер)

**Найбільша робота голосу — не тон (він рівний), а НОМЕНКЛАТУРА:** одні й ті самі сутності
й дії названо по-різному між екранами (§1 A–E, §2 A–E). Джерело правди має зафіксувати **по одному
канонічному імені** на: перемикач-члена, критичний-блок, поточні-ліки, вимірювання-аналізу,
проєкцію-анамнез, поле-випередження, поле-лікар, збереження (Зберегти vs Готово). Межа (§4) —
трима­ється; головне при поліруванні — **не завести оцінку/норму, редагуючи ці рядки**.
