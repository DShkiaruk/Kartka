## 3. Верифіковано ЧИСТО (презумпція дефектів не підтвердилась)

- **МЕЖА (головний ризик)** — жодного натяку на норму/зону/оцінку/стрік/статистику/пораду
  в UI-тексті всіх 43 екранів. Крива R4 = слот+сирі значення+зум; журнал R3 = сирі події;
  анамнез «неповна» = факт-позначка; нотатки візиту атрибутовані лікарю («лікар радив»), не Kartka.
- **Стани з матриці** — усі ✓-клітинки `_screens.md` мають файл або задокументований спільний
  представник (loading/error). Пропущених станів немає.
- **Глухий кут** — усі виходи на місці й наші, не generic (empty→`edit-base-card`,
  deadempty→`edit-base-card`, R2-offline→`emergency-card`, save-error→durable+Повторити).
- **Вигляд** — нуль кольору/тіней/`<img>`/радіусів/`style=` в HTML; емодзі лише в
  коментарях/wf-note, не в UI. Сіре через спільний CSS + слот-бокси.
- **Заглушки** — lorem немає; `.todo` = доменні лейбли порожніх полів. Ліки/візити/roster консистентні.
- **Екран не з карти** — сиріт немає; усі мапляться на sitemap/`_screens.md`.
- **Патерни** — оверлей §7 (scrim+sheet+dialog ×3), shell, loading/error, @container-брейкпойнт — консистентні.
