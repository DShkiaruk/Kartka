# Референси — Kartka (відкриття фази `concept/`)

**Що це.** Вхідний матеріал для візуальних рішень — **не рішення й не застосування**.
Каркаси лишаються сірими; `tokens/` і `design-system/` не чіпаємо (наступні ланки).
Тут — банк прийомів, з якого фаза `concept/` (і `tokens/`) черпатиме.

**Метод.** Mobbin MCP, режим `screens` / `flows`, запити-речення про видимі елементи
(не тег-списки). Пріоритет iOS/mobile (Kartka — PWA mobile-first). Кожен екран
**переглянуто напряму** (скриншот через MCP, curated by Mobbin), опис — з побаченого,
не з метаданих. Дата збору: 2026-07-19.

**Головний критерій — не естетика, а ВІЗУАЛЬНА МЕЖА.** Стрижень Kartka «не судимо»
(SaMD-межа) тепер має візуальний вимір: **колір оцінює без слів.** Червоне значення,
зелена галочка, світлофор, target-line, стрілка вниз, зона «норми» на графіку — це
оцінка засобами дизайну, і вона порушує межу так само, як слово «у нормі». Тому
референс тут — **хто показує медичні дані нейтрально** (значення+дата без розфарбування,
крива без зон). Такий цінніший за просто гарний. Показник, підсвічений «поза нормою», —
**анти-референс**, хай навіть красивий.

**Легенда межі:**
- ✅ **референс** — показує нейтрально (значення+дата без оцінки кольором);
- ⛔ **анти-референс** — оцінює кольором/зоною/ярликом (чого уникати);
- ◐ **змішаний** — прийом брати, оцінкову деталь відкинути.

**Тривоги персони** (з `research/personas.md`, емоційні jobs): **E1 — підготовленість**
(за секунди показати лікарю все, нічого не забути); **E2 — приватність** (довіра, що
дані родини під контролем і не «витечуть»).

**Правило вибірки:** не копіюємо екран цілим. Один — за основу, 1–2 конкретні прийоми —
з інших. Прийом = радіус картки / місце позначки / скільки кольору / як подано
значення+дата, а не «враження». Нижче — вже відфільтровано; проходні/не-в-тон екрани
опущено.

## Синтез — що брати за основу, що прищепити

**Основа + прийоми, по екранах Kartka:**

- **Базова картка / хаб «Записи»** ← *Plazo* (основа: спокійний список-рядки) + *Apple
  Health* details-card (інтейк label/value) + *Shangri-La* маскування імені.
- **Список вимірювань** ← *Apple Health* All-Data (основа: value+дата+chevron, колір лише
  на іконці) + *Withings* каркас картки (без якісного ярлика).
- **Крива показника** ← нейтральний каркас **без зон** + *The Outsiders* тултип
  value+дата + підпис точок + селектор діапазону.
- **Профілі / перемикач родини** ← *Amazon Family* сітка карток + «+ Add member».
- **Порожній стан** ← *Gymshark* (основа) + *Aaptiv* «you'll see it here».
- **Приватність** ← *Withings* consent-екран + *GoodRx* рядок доступу + *Alan* / *Shangri-La*
  маскування чутливих полів.
- **Тон** ← *Alma* (теплість, serif, повітря) — але **дані завжди нейтрально**.

**Візуальні анти-патерни (звід — чого уникати):**

1. Зона / заштрихована смуга «норми» на графіку.
2. Baseline- або target-лінія на кривій.
3. Ярлики Good / Fair / Poor / Normal / «personal range» біля значення чи на осі.
4. Світлофор: зелена галочка = ок, червоне = погано.
5. Range-gauge (вертикальний кольоровий термометр біля показника).
6. Крапка-на-шкалі-діапазону («де ти в нормі»).
7. Кольорове саме **значення** (червоний HR) або стрілка вгору/вниз як оцінка.
8. Якісний ярлик під значенням («High HR», «Gaining muscle»).
9. Жартівливий тон у порожньому стані («Eek!») — не наш регістр.

**Єдиний виправданий акцент** — алергії / екстрений екран: **факт-прапорець**, не
судження; стримано, не поширювати «тривожно-червоне» на звичайні дані.

# Факт-прохід — 7 обраних застосунків (візуальний смак)

Окремий захід: 7 застосунків, які **обрав користувач** (подобаються візуально) —
Hers · Apple Health · GO Club · Lovi · Stoic · Alma · Apple Fitness (iOS). Прохід
**фактичний** — лише те, що видно на реальних екранах (не метадані, не з памʼяті);
кожне «спокійно/тепло» спирається на видиму деталь. По кожному: тип · прийоми
(як зверстано) · межа (чи оцінює — назвати прямо) · вердикт. Основу тут **не обираю**
(рішення користувача). Дата: 2026-07-19.

**Вердикти:** РЕФЕРЕНС (нейтральний показ) · ЕСТЕТИКА-ТАК-ЛОГІКА-НІ (гарний, але оцінює —
беремо форму, не логіку) · АНТИ.

### Hers · [home ↗](https://mobbin.com/screens/32d65904-5181-40db-bd79-66deea82d784) · [консультація ↗](https://mobbin.com/screens/34722beb-5c0b-4c76-91e4-6195a60a65b0)
**Тип:** телемед — керування лікуванням/підпискою + консультація-інтейк.
- **Прийоми:** дуже білий, повітряний; **один сильний акцент — чорні CTA-банери** на білому; велика фото-картка препарату (радіус ~16, щедрий падінг); **двоколонкові pill-стат-картки** («Med reminders · On», «7 remaining»); дрібні **uppercase-сірі секційні лейбли** («FROM YOUR PROVIDER TEAM»); горизонтальний степер-трекер замовлення (Requested→Delivered) з градієнт-лінією; число+дата простим текстом («Refills on Friday, Dec 19»).
- **⚠ Межа:** екран лікування — **не оцінює**. Але у консультації: **score «Severe Anxiety 16/21» + позиційний слайдер «Medication zone / You are here»** = оцінка результату тесту + зона. (Гіпотеза Hers=lab Action-Plan підтверджується у формі assessment-score.)
- **Вердикт:** форма — **РЕФЕРЕНС** (білий спокій, один чорний акцент, uppercase-секції, двоколонкові pill-факти); логіка score+zone у тесті — **уникати**.

## Підсумок факт-проходу: форма взяти / логіка уникати

**Форма — взяти (нейтральна):**
1. Рядок «іконка-категорії + назва + дата + велике число + одиниця» — колір лише на іконці *(Apple Health)*.
2. Монохром + типо-ієрархія вагою/сірим; uppercase-лейбл + час справа *(Stoic)*.
3. Щільний факт-рядок «іконка·значення·одиниця» для 10-сек скану *(GO Club)*.
4. Один сильний акцент на спокійному тлі; чорні CTA; uppercase-секції; двоколонкові pill-факти *(Hers)*.
5. Pill-чіп-мультивибір, степер «X/Y», day-selector *(Lovi)*.
6. Тепле тло (sage/cream) + мʼякі картки + serif-заголовки + повітря *(Alma)*.
7. Картка «велике-число + одиниця + блідий спарклайн»; категорійне колір-кодування *(Apple Fitness / Apple Health)*.

**Логіка — уникати (оцінка):**
1. Score / бал — Alma Score, Hers «16/21», Lovi «99% fit».
2. Кільце-гейдж прогресу до цілі — Apple Fitness ring, Alma macro-rings.
3. Зона / «Medication zone» / per-range слайдер — Hers.
4. Average / target / baseline-лінія на графіку — GO Club, Apple Health Highlights, Alma «Goal».
5. Колір на самому значенні / mood-шкали «Bad…Awesome» — Lovi.
6. Streak / record / challenges / awards як тиск — Alma, Apple Fitness.
7. Порівняння score між людьми — Alma «59 You / 40 JS».

> **Наскрізний висновок.** Тепло і спокій самі по собі **межу не порушують** — порушує
> **scoring**, який ці застосунки на теплоту навісили (Alma — найяскравіше). Kartka бере
> **форму** (теплоту / спокій / щільність / великі скановані числа) і лишає **число+дата
> нейтральним** — без score / кільця / зони / average-лінії.
