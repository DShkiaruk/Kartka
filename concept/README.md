# Concept — Kartka

Воркстрім **візуальної мови продукту**: від банку прийомів до обраного напряму,
його застосування на каркасах і записаних альтернатив. Джерело рішень —
[`concept.md`](./concept.md) (§9: MD веде HTML; стенди — лише відображення).

- **Обраний напрям продукту — Ґ «Фокус + Список»** (застосовано на
