# Concept — Kartka

Воркстрім **візуальної мови продукту**: від банку прийомів до обраного напряму,
його застосування на каркасах і записаних альтернатив. Джерело рішень —
[`concept.md`](./concept.md) (§9: MD веде HTML; стенди — лише відображення).

## Стан

- **Обраний напрям продукту — Ж «Фокус + кадри»** (синтез, що **розвиває Ґ**:
  успадковує скін Тиші + фіксації ч.5, додає кадрову мову Є). Рішення автора, 2026-08.
- **Ґ** — записана база-скін; **Д·Е·Є** — простежувані альтернативи методу кубиків.
- **Застосування:** скін Ґ на `wireframes/dashboard*` + Аналізи (`_lang-g.css`);
  ⚠ перенос на мову Ж (тайли, слайдер, 1-в'юпорт) — наступний крок.
- Демо-дані всіх стендів — канон [`../wireframes/_fixtures.md`](../wireframes/_fixtures.md)
  (грепи самоперевірки всередині).
- Межа §4 «показує, не судить» — гейт кожного стенду (блок межі — у шапці кожного).
