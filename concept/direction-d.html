Напрям Д «Викрійка» — стенд дашборда · рендиція v2 «синька»

Четвертий концепт методом кубиків (рол 45fdc353, деталі — concept.md ч.4). Рендиція v2: викрійку друкуємо синькою — drenched прусська синь, білі лінії, органічні лекала-форми, золота крейда. Дані — строго з _fixtures.md. Обраний напрям продукту — Ж «Фокус + кадри» (розвиток Ґ).

§4 Межа «показує, не судить» — гейт світу. Синь = матеріал копії, не стан даних. Золота крейда = розмітка активного/дій, ніколи значення. Розмірна стрілка = число + дата; найбільша = роль «останній вимір у фокусі». Крива — біла сира лінія по наколках, без зон/норм/target.

П'ять законів світу (рендиція v2)

Граматика викрійки, віддрукованої на світлокопії.

Палітра / матеріал

Прусська синь аркуша на темному паспарту; білі лінії копії; молочний текст; золота кравецька крейда лише на активному й діях.

Типо / композиція

Молочні моноширинні цифри й мітки; sans для тексту; деталі — органічні криві контури лекал; «✂ лінія розрізу» членує аркуш.

Топологія

Аркуш = профіль-день; вушка шарів = родина (активний шар — золота крейда); деталі-лекала = кластери (критичне · сьогодні · попереду · останнє).

Контроли / стани

Суцільний контур = зафіксовано; штрих-пунктир = заплановано; крейдовий кружок = факт прийому; крейда = вибране/активне.

Адаптив / рух

Мобілка — рулон синьки; десктоп — розгорнутий аркуш зі стосом копій під ним. Рух: розгортання шару 150–250 мс; reduced-motion — без.

Мобільна поверхня

Синька Олени. Кластери — зі sitemap.md, дані — _fixtures.md.
