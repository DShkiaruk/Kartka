Напрям Ж «Фокус + кадри» — стенд дашборда · ✅ обраний напрям продукту

Обраний напрям продукту (рішення користувача, 2026-08) — синтез, що розвиває Ґ (пін б'є рол; рішення й формула — concept.md ч.4): база = скін Ґ (світло, критичне помітне, повний список прийомів, чек-кнопки, Момент), від Є — лише графічність кадрів, дуотонові ілюстрації та слайдер для Візитів·Документів, перефарбовані в indigo-мову Тиші. Дані — строго з _fixtures.md.

§4 Межа «показує, не судить» — гейт світу. Чек-кнопка = факт прийому (акцент Тиші, не зелений «молодець»). Дуотонова ілюстрація = категорія факту (шприц · серце · крапля · кабінет · бланк) — без алярм-кольорів і знаків оклику, серце ≠ «поганий стан». Слайдер = гортання записів, не рейтинг. Значення — чорнилом; 3rem = роль «Момент у фокусі» (5.1), не значення.

П'ять законів світу

Скін Тиші + кадрова мова Є, і головний закон синтезу: операційне ≠ довідкове.

Палітра / матеріал

Скін Тиші: прохолодний нейтрал, білі пласкі картки, один indigo; дуотон ілюстрацій = tint-ґрунт + акцентні штрихи (категорія, не стан).

Типо / композиція

System-sans; Момент 3rem/300 за роллю (5.1); tabular-цифри; операційні кластери — вертикальними списками, довідкові — картками-кадрами.

Топологія

Операційне (критичне · сьогодні · останнє) = списки, завжди видимі повністю; довідкове (візити · документи) = горизонтальна стрічка кадрів зі снапом.

Контроли / стани

Чек-кнопка прийому ≥44px тач-зони, заповнюється акцентом + слово «прийнято»; кадр = запис (тап → деталь); «＋ додати» = порожній кадр у кінці стрічки.

Адаптив / рух

Мобілка — списки + стрічка; десктоп — 2-колонна основа Ґ, стрічка на всю ширину, міні-крива Моменту. Рух лише станів: чек, снап гортання, 150–250 мс.
